## 2. MashaGPT

*Агрегатор с приложениями.*

- Нативные приложения для Windows, macOS, iOS и Android и расширение для Chrome.
- Режим проектов с загрузкой документов и редактор кода.
- Оплата картой РФ и через СБП, есть небольшой бесплатный дневной лимит.
- По данным сервиса, в нём больше 50 нейросетей и ИИ-инструментов, среди них музыка и видео.

**Кому подойдёт:** тем, кто любит отдельные приложения вместо браузера.

## 3. ChadGPT

*Автоподбор модели.*

- Автоподбор: сервис сам выбирает модель под запрос, разбираться в моделях не нужно.
- Приложения для iOS, Android и RuStore.
- В обзоре vc.ru назван сервисом с одним из самых широких наборов моделей.
- Несколько бесплатных запросов в день и оплата картой РФ.

**Кому подойдёт:** тем, кто не хочет выбирать модель вручную.

## 4. Syntx

*Нейросети в Telegram.*

- Работает в Telegram-боте: ничего ставить не нужно, при регистрации дают стартовые токены.
- По обзору vc.ru (апрель 2026), больше 70 моделей.
- Сильные инструменты для фото: замена лица, удаление фона, оживление изображений, клонирование голоса.
- Общая лента генераций, где можно посмотреть работы других пользователей.

**Кому подойдёт:** для быстрых экспериментов с картинками и текстом прямо в мессенджере.

## 5. BotHub

*Библиотека промптов и Midjourney.*

- Midjourney в русскоязычном интерфейсе.
- Готовые форматы для текстов и большая библиотека промптов.
- Стартовый бонус внутренней валюты CAPS, оплата пакетами или подпиской.
- Подходит, чтобы быстро начать с готовыми шаблонами.

**Кому подойдёт:** тем, кому нужны шаблоны и промпты под типовые задачи.
